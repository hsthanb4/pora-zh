如第 2 章与第 3 章所述，自主系统通过一个从战略决策到实时控制的过程层次，把高层目标转化为具体的物理动作。开环轨迹优化为生成动态可行的状态序列与控制序列提供了有原则的框架，但它往往难以处理复杂的、依赖状态的约束，例如避碰。此外，轨迹优化方法通常只给出**局部最优**解，其质量强烈依赖初始化，可能无法捕捉问题的全局结构。

为应对这些局限，本章聚焦**运动规划**（motion planning），它采取更**全局**的视角，显式推理环境约束、障碍物与轨迹可行性的整体。为保持计算可处理性，运动规划通常依赖简化的动力学模型，给出粗粒度或几何形式的路径，以保证无碰撞导航。实践中，运动规划与轨迹优化往往互补：运动规划通过找到一条初始无碰撞路径来确立全局可行性，轨迹优化再把这条路径细化为平滑、动态一致且经过优化的轨迹。

运动规划问题在 1970 年代被形式化定义，其研究历史相当丰富。1980 年代的早期工作聚焦于精确的组合式算法，力求以数学的严格性刻画位形空间的几何。这些方法在理论上优雅，但在高维问题上遭遇严重的计算瓶颈。1990 年代随着采样方法的引入出现了范式转变，为复杂的运动规划问题提供了可扩展的解法。2000 年代，规划算法被大规模部署到实时系统上，从自动驾驶汽车到机械臂。今天，运动规划研究依然活跃并不断扩展，关注融合微分约束与逻辑约束、不确定性下的规划、利用并行计算，以及引入基于学习的方法。

运动规划的重要性体现在其应用的广度上。仅举几例：在自动驾驶中，规划算法为在密集车流中行驶的车辆计算安全高效的机动动作；在人形机器人中，规划器为行走、攀爬或在杂乱环境中操作等任务协调全身运动；在手术机器人中，运动规划用于设计在人体内部精确、无碰撞的工具轨迹。即使在经典机器人之外，运动规划技术也已在蛋白质折叠等领域找到应用——需要在高维位形空间中穿行，以确定蛋白质的折叠路径。

过去几十年里，人们发展出多种算法来求解运动规划问题。这些方法通常归为四大类：基于栅格的规划、组合式规划、基于采样的规划与势场法。概括地说，**基于栅格的规划器**把机器人的环境离散为栅格，并用图搜索算法在栅格单元中计算一条可行路径。**组合式规划器**构造位形空间的显式表示，刻画规划所需的自由空间的连通性。**基于采样的规划器**利用随机采样与碰撞检测逐步探索位形空间，对显式表示变得不可行的高维问题具备可扩展性。最后，**势场法**构造人工势函数，把机器人吸向目标，同时把它推离障碍物。

本章先在第 4.1 节形式化定义运动规划问题，引入核心概念与记号。随后讨论上述四大类算法范式，即第 4.2 节的基于栅格的规划、第 4.3 节的组合式规划、第 4.4 节的基于采样的规划，以及第 4.5 节的势场法。

# 问题表述

我们先给出运动规划问题最基本的形式化定义。令 $\mathcal{W}\subseteq\mathbb{R}^{2}$ 表示机器人的**工作空间**（workspace），即机器人所处的物理环境。工作空间内存在已知的障碍区域 $\mathcal{O}\subset\mathcal{W}$，其边界为多边形（分段线性）。机器人本身建模为一个刚性多边形，必须在工作空间中穿行而不与任何障碍物相交［旁注：对三维工作空间，唯一的差别是 $\mathcal{W}\subseteq\mathbb{R}^{3}$，且机器人与障碍区域用多面体表示。］［旁注：这里给出的基本表述可以远远超出刚性多边形与多面体的范围，推广到几何形状复杂的机器人。关于这些推广的深入讨论，请参阅 LaValle (2006)。］。

在这一设定下，基本的运动规划问题可以非正式地表述为：*给定机器人的初始摆放，计算如何把它逐步移动到期望的目标摆放，且不与任何障碍物碰撞。* 作为示例，考虑图 4.1 的工作空间，任务是把一个 L 形机器人从初始位置移动到目标位置，同时避开多边形障碍物。此时运动规划算法的输出，是机器人从起点到目标之间所有中间变换构成的一条路径。

虽然运动规划问题自然地在机器人的工作空间中描述，但它实际上活在另一个空间里：描述机器人所有可能摆放的刚体变换的集合。如第 1 章所述，这个集合称为**位形空间**（configuration space）或 $\mathcal{C}$ 空间。在这一表述下，工作空间中的障碍物在位形空间 $\mathcal{C}$ 中诱导出禁行区域，运动规划问题就归结为在 $\mathcal{C}$ 中找一条避免碰撞的连续路径。

下面用一个例子简要回顾位形空间的概念。

$$
\bm{x}=\begin{bmatrix}x&y&\theta&\dot{x}&\dot{y}&\dot{\theta}\end{bmatrix}^{%
\top},

$$
\bm{q}=\begin{bmatrix}x&y&\theta\end{bmatrix}^{\top},
$$

它完整刻画了机器人的自由度。换句话说，$(x,y,\theta)$ 的每种组合都对应机器人在工作空间中的唯一摆放，称为一个**位形**（configuration）。这一抽象简化了问题：我们不再为完整状态计算轨迹，而是寻找一串无碰撞的位形，如图 4.1 右侧的图形所示。得到的位形空间几何路径可以交给轨迹优化方法细化——使它们能够纳入系统动力学——随后再交给闭环控制方法（例如第 3 章介绍的跟踪控制器）执行。

关键在于，位形空间的概念可以推广到几何更复杂、自由度更高的机器人（例如多关节机械臂）。

### 位形空间中的自由空间

运动规划的一个基本概念是**自由空间**（free space），记作 $\mathcal{C}_{\mathrm{free}}$。直观地说，$\mathcal{C}_{\mathrm{free}}$ 是机器人不与工作空间中任何障碍物碰撞的全部位形构成的集合。形式上，令 $R(q)\subseteq\mathcal{W}$ 表示机器人处于位形 $q$ 时在工作空间中所占据的点集。自由空间定义为：

$${#eq4.1}
\mathcal{C}_{\mathrm{free}}=\{q\in\mathcal{C}\,|\,R(q)\cap\mathcal{O}=%
\emptyset\}.
$$

类似地，位形空间中的**障碍区域**记作 $\mathcal{C}_{\mathrm{obs}}$，定义为自由空间的补集：

$${#eq4.2}
\mathcal{C}_{\mathrm{obs}}=\{q\in\mathcal{C}\mid R(q)\cap\mathcal{O}\neq%
\emptyset\}.
$$

一旦算出了 $\mathcal{C}_{\mathrm{free}}$（以及相应的 $\mathcal{C}_{\mathrm{obs}}$），机器人的物理尺寸就不再需要显式考虑，机器人可以当作在位形空间中运动的质点处理，如上一例所示。借助这一抽象，机器人与环境的几何复杂性都被吸收进位形空间自身的结构之中。

# 基于栅格的运动规划

简化运动规划问题的一种自然做法，是把机器人连续的位形空间离散成栅格。我们不再推理无穷多个可能位形，而是把环境划分为有限个单元来近似。每个单元被分类为自由（即无碰撞，机器人可以占据）或禁行（即会导致与障碍物碰撞）。机器人可以在相邻的自由单元之间移动，规划任务就归结为找一串连通的自由单元，从起点通向目标。

这种离散化自然地把运动规划转化为**图搜索问题**。具体来说，栅格中的每个自由单元表示为图中的一个顶点，当两个单元相邻且都自由时，就在对应顶点之间加一条边。形式上，我们构造图 $\mathcal{G}=(\mathcal{V},\mathcal{E})$，其中每个顶点 $v\in\mathcal{V}$ 对应一个自由单元，每条边 $(v,u)\in\mathcal{E}$ 对应机器人在相邻单元之间的一次合法移动。于是规划就变成在图中找一条从起始顶点到目标顶点的路径。

这一视角很有力，因为它让运动规划可以借用图论与计算机科学数十年的成果。原本用于求解最短路问题的算法——如广度优先搜索或 Dijkstra 算法——可以直接用于运动规划。换句话说，「在带障碍物的空间中穿行」这个看似几何的问题，被归约为「在图中找一条路径」这个纯组合问题。不过这种做法依赖于对 $\mathcal{C}_{\mathrm{free}}$ 的显式刻画，而构造栅格、把每个单元分类为自由或占据正需要这一刻画。实践中获得这种精确刻画往往不可行——尤其在高维位形空间中——因此需要其他策略，例如本章后面讨论的基于采样的规划。

### 连通性与邻域结构

邻接关系的定义方式取决于机器人模型与所选栅格结构：

- 4 连通栅格中，每个单元最多有四个邻居（上、下、左、右）。
- 8 连通栅格中还允许对角移动，每个单元最多有八个邻居。
- 更一般地，可以考虑 $k$ 连通邻域（例如 16 连通）或六边形网格，在简单性、路径质量与计算代价之间做权衡。

连通性的选择有实际后果。较粗的邻域可能限制机器人逼近平滑轨迹的能力，而更丰富的邻域会增加分支因子与搜索复杂度。无论具体选择如何，关键在于栅格结构诱导出一个定义良好的图，搜索算法可以在其上运行。

## 标签修正算法

一旦运动规划问题被表述为图搜索，下一步就是设计一个系统地探索该图、寻找从起点到目标路径的算法。用于此任务的一大类强有力方法称为**标签修正算法**（label-correcting algorithm）。

「标签」一词指的是与图中每个顶点关联的一个数值，表示从起始顶点到该顶点目前已知的最佳路径代价。概括而言，标签修正算法通过迭代改进这些代价标签来推进。初始时只有起始顶点的代价标签为零，其余全部初始化为无穷（或未定义状态）。算法在探索图的过程中，一旦发现通往某个顶点更好（代价更低）的路径，就更新——也就是**修正**——相应的标签。

形式上，令 $q_{\mathrm{S}}$ 表示起始顶点、$q_{\mathrm{G}}$ 表示目标顶点［旁注：这里用记号 $q$ 表示图顶点，是为了强调图搜索与位形空间路径规划之间的联系——后者中 $q$ 通常表示一个位形。］。对每个顶点 $q$，令 $C(q)$ 表示其标签，即目前找到的从 $q_{\mathrm{S}}$ 到 $q$ 的最佳路径代价。这个值也称为**到达代价**（cost of arrival）。

标签修正算法维护一个**前沿**（frontier，也称**活动集**（alive set）或**优先队列**（priority queue）），其中是那些邻居仍可能获得代价改进的顶点。每次迭代从前沿中取出一个顶点 $q$ 并**扩展**它。**扩展**指的是检查从 $q$ 指向其邻居顶点 $q^{\prime}$ 的所有出边。对 $q$ 的每个邻居［旁注：在图论中，两个顶点若由一条边相连，就互称邻居。］ $q^{\prime}$，算法尝试改进（或**松弛**（relax））与 $q^{\prime}$ 关联的当前代价估计。具体来说，给定代价为 $c(q,q^{\prime})$ 的边 $(q,q^{\prime})$，松弛步骤检验经由 $q$ 的路径是否给出比此前已知的任何路径更低的到 $q^{\prime}$ 的到达代价，即是否满足：

$$
C(q)+c(q,q^{\prime})<C(q^{\prime}).
$$

若该条件成立，则更新 $q^{\prime}$ 的标签（即 $C(q^{\prime})$），并把 $q^{\prime}$ 重新插入前沿以便继续探索。这一过程持续到没有任何标签还能被改进为止。

### 标签修正算法的一般结构

这一类中的所有算法都具有如下结构：

- **初始化：** 置 $C(q_{\mathrm{S}})=0$，对其余所有顶点 $q$ 置 $C(q)=\infty$。用起始顶点初始化前沿 $Q=\{q_{\mathrm{S}}\}$。
- **主循环：** 在前沿 $Q$ 非空之前重复：
- 1. 按特定的**选择规则**从前沿 $Q$ 中取出一个顶点 $q$［旁注：选择规则的取法，是不同标签修正算法之间的主要区别。］。
- 2. 对 $q$ 的每个邻居 $q^{\prime}$ 执行松弛步骤，即：
- （a）检查是否 $C(q)+c(q,q^{\prime})<C(q^{\prime})$。
- （b）若是，则更新 $C(q^{\prime})\leftarrow C(q)+c(q,q^{\prime})$，并把 $q^{\prime}$ 加入前沿 $Q$（若尚未在其中）。
- **终止：** 前沿为空时算法终止。此时 $C(q)$ 给出了从 $q_{\mathrm{S}}$ 到每个可达顶点 $q$ 的最短路径代价。

标签修正算法一般结构的伪代码见算法 4.1。

```text
Data: q_S, q_G, directed graph G = (V, E), edge costs c(·,·), selection rule Select
Result: Shortest path from q_S to q_G (if reachable)

for q ∈ V \ {q_S} do
    C(q) ← ∞
C(q_S) ← 0
Q ← {q_S}                          /* Initialize priority queue */

while Q is not empty do
    q ← Select(Q); Q.remove(q)
    for q′ ∈ {u | (q,u) ∈ E} do
        C̃ ← C(q) + c(q,q′)
        if C̃ < C(q′) then
            C(q′) ← C̃; parent(q′) ← q
            if q′ ≠ q_G and q′ ∉ Q then
                Q.add(q′)

if C(q_G) = ∞ then
    return N.A.                    /* Goal unreachable */
else                               /* Reconstruct path by backtracking parents */
    path ← []; q ← q_G
    while q ≠ q_S do
        path.prepend(q); q ← parent(q)
    return path
```

### 选择规则的作用

选择下一个要扩展的顶点所用的选择规则，是区分各种标签修正算法的关键因素之一，最终决定了它们的效率与性能。若干经典搜索方法都可以看作标签修正框架的特例，例如：

- **深度优先搜索（DFS）：** 在 DFS 中（图 4.5），前沿按**栈**（后进先出）管理。这意味着算法总是沿着最近发现的路径继续深入，然后才回溯。DFS 的吸引力在于简单、内存占用低——活跃节点数正比于搜索深度。但 DFS 有陷入搜索树中深而无用分支的风险，导致寻找最短路径的性能很差。

![图 4.5：深度优先搜索](/book-assets/motion-planning/_tikz__motion-planning-1.svg)

- **广度优先搜索（BFS）：** 在 BFS 中（图 4.6），前沿是一个**队列**（先进先出）。算法先扩展给定「深度」上的所有节点，再进入下一层，从而以环绕起始节点的同心层方式探索图。与 DFS 相比，BFS 需要多得多的内存，因为它必须存下某一深度上的所有前沿节点。

![图 4.6：广度优先搜索](/book-assets/motion-planning/_tikz__motion-planning-2.svg)

- **Dijkstra 算法（也称最佳优先搜索）：** 在 Dijkstra 算法中（算法 4.2），前沿是按暂定标签 $C(q)$（即目前找到的最佳到达代价）排序的优先队列。每次迭代选取标签最小的顶点进行扩展。形式上，把这种对下一个顶点的贪心选择写成：

$${#eq4.3}
\mathsf{Select}(Q)=\arg\min_{q\in Q}C(q).
$$

Dijkstra 算法的一个关键性质是：一旦某个顶点从优先队列中取出，它的标签就保证是最终且最优的。换句话说，每个节点至多被扩展一次，从而使图的探索更高效。正因如此，Dijkstra 算法为 $A^{*}$、$D^{*}$ 等许多广泛使用的规划方法奠定了基础。

```python
def dijkstra(start_node, edges):
    visited = set()
    Q = [(0, start_node)]

    while Q:
        current_cost, current_node = heapq.heappop(Q)
        if current_node in visited:
            continue
        visited.add(current_node)

        for neighbor, edge_cost in edges[current_node]:
            if neighbor in visited:
                continue
            new_cost = current_cost + edge_cost
            if new_cost < neighbor.cost:
                neighbor.cost = new_cost
                neighbor.parent = current_node.idx
                heapq.heappush(Q, (new_cost, neighbor))
```

### 超越 Dijkstra：面向运动规划的更知情搜索

由于简单、并且保证只要存在最优路径就一定能找到，Dijkstra 算法是图搜索中最常用的方法之一［旁注：24. Bertsekas, D. *Dynamic Programming and Optimal Control*. Athena Scientific, 2000.］。特别地，Dijkstra 是一个**正确**（correct）的算法：只要从起始节点到目标节点存在路径，它总能找到代价最小的那条。

::: thm 定理 4.1（图搜索算法的正确性；Bertsekas (2000)［旁注：2. Bertsekas, D. *Dynamic Programming and Optimal Control*. Athena Scientific, 2000.］）
若从 $q_{\mathrm{S}}$ 到 $q_{\mathrm{G}}$ 存在可行路径，则算法在有限时间内终止，且 $C(q_{\mathrm{G}})$ 等于最优通行代价 $C^{*}(q_{\mathrm{G}})$。
:::

这一性质让 Dijkstra 颇具吸引力，但它的探索策略可能造成大量无用功。Dijkstra 总是扩展累计到达代价最小的前沿节点，因此实际上是以从起点向外辐射的「代价等高线」方式探索搜索空间。这一策略保证了所返回路径的最优性，但可能扩展许多与到达目标无关的顶点——在运动规划中典型的大型结构化图上，这一缺点尤为突出（见图 4.8）。

这些局限促使人们发展更知情的搜索策略，引入指向目标的额外引导。其中影响最大的是 $A^{*}$ 算法——它在 Dijkstra 之上加入对剩余代价的启发式估计；以及它的动态扩展 $D^{*}$ 算法——随着关于环境的新信息出现而调整搜索。

![图 4.8：Dijkstra 在基于栅格的运动规划中的扩展过程。算法从 $q_{\mathrm{S}}$ 出发，从前沿（交叉阴影填充的节点）中选出到达代价最低的节点进行扩展（实心填充的节点是此前已访问过的）。这样一来，扩展过程可能包含对到达 $q_{\mathrm{G}}$ 并无帮助的区域。](/book-assets/motion-planning/_tikz__motion-planning-4.svg)

### A∗ 算法

$A^{*}$ 算法改进了 Dijkstra 的选择规则：在到达代价之上加入对剩余代价（即从当前节点到目标的代价）的启发式估计。形式上，$A^{*}$ 不扩展使 $C(q)$ 最小的顶点，而是扩展使下式最小的顶点：

$${#eq4.4}
f(q)=C(q)+h(q),
$$

其中 $h(q)$ 是估计从 $q$ 到目标的最优剩余代价的启发式函数。相应地，对 $q$ 的每个邻居 $q^{\prime}$，松弛步骤也被加强为更新 $f(q^{\prime})$，而不再只更新到达代价 $C(q^{\prime})$：

$${#eq4.5}
f(q^{\prime})\leftarrow\min\big{(}f(q^{\prime}),C(q)+c(q,q^{\prime})+h(q^{%
\prime})\big{)}.
$$

只要 $h(\cdot)$ 是**可容许的**（admissible，即从不高估真实剩余代价），$A^{*}$ 就保证返回最优路径。直观地说，低估剩余代价可以确保节点不会被过早丢弃，否则可能导致次优解。实践中，诸如到目标的欧氏距离或曼哈顿距离这类启发式常常能减少被探索的顶点数，因为搜索被引向目标，而不是朝各个方向均匀扩展。这使 $A^{*}$ 成为运动规划中最广泛使用的图搜索算法之一。

### D∗ 算法

在许多机器人应用中，环境事先只有部分已知，执行过程中可能发现新信息（例如此前未观测到的障碍物）。每当地图变化就从头重算一次 $A^{*}$ 搜索，在计算上可能很有挑战性。$D^{*}$ 算法（**Dynamic A∗**）通过增量修复来应对：一旦检测到变化，它并不丢弃已有的搜索树，而是高效地更新代价标签与前沿优先级，尽可能复用过去的计算。这使它特别适合动态或不确定环境中的自主导航——机器人必须随着新信息的获取在线调整规划。关于 $D^{*}$ 的深入讨论，请参阅 Stentz (1995)［旁注：3. Stentz, A. “The focussed D∗ algorithm for real-time replanning.” In *14th International Joint Conference on Artificial Intelligence*, 1652–1659, 1995.］。

### 基于栅格规划的优缺点

基于栅格的规划方法有几个吸引人的优点，这解释了它们在机器人领域长期流行的原因。也许最重要的好处是**简单**：把位形空间离散为单元、把规划当作图搜索问题来处理，这一基本想法易于实现也易于推理。一旦栅格构造完成，DFS、BFS 或 Dijkstra 等经典搜索算法就可以直接应用。这也使基于栅格的方法在某些情形下相对**快速**，尤其是当栅格分辨率与环境尺度、障碍物复杂度匹配得当时。

尽管有这些优点，基于栅格的方法也有重要局限。第一个挑战是它们本质上**依赖分辨率**。若栅格分辨率过粗，狭窄通道或细微的障碍边界可能被漏掉，即使连续空间中存在可行解，规划器也可能找不到。反之，使用极细的栅格会显著增加计算负担，因为栅格单元数随分辨率变细而迅速增长。因此，在分辨率与可处理性之间取得恰当的折中并不简单。

第二个缺点是，基于栅格的规划在机器人复杂度增加时扩展性很差。它对在二维工作空间中运动的简单二维机器人（即位形空间与工作空间重合的情形）有效，但栅格规模会随机器人自由度（DOF）的数量**指数级**增长。此外，基于栅格的规划需要对自由空间 $\mathcal{C}_{\mathrm{free}}$ 的精确刻画，而这在高维位形空间中往往难以计算。这些局限促成了基于采样的方法，4.4 节将讨论它们。因此，基于栅格的方法主要用于自由度较少的机器人，或位形空间维数被有意降低的简化规划问题。

总之，基于栅格的规划仍然是一种广泛使用且重要的方法，尤其适用于低维问题。但它对离散化的依赖以及随维数的指数级扩展，限制了它在更复杂机器人系统上的适用性。

# 组合式运动规划

本节回到运动规划问题的**连续**表述，讨论组合式方法。其核心思想是构造自由空间 $\mathcal{C}_{\mathrm{free}}$ 连通性的精确表示，而不借助近似。组合式方法不对空间做任意离散化，而是计算一张**路线图**（roadmap），用它捕捉 $\mathcal{C}_{\mathrm{free}}$ 的本质拓扑结构，从而支持在连续空间中的规划。

由于这一性质，组合式运动规划算法被称为**精确**（exact）的——它们直接在连续位形空间中找路径，不依赖近似。组合式规划器也是**完备**（complete）的：只要存在路径就保证找到最优路径，否则正确报告失败。这与基于栅格的规划器形成对比——后者只是**分辨率完备**的，只在所选离散分辨率下存在解时才保证找到。

不过，与基于栅格的方法一样，组合式规划在高维位形空间中会变得计算困难，因为计算 $\mathcal{C}_{\mathrm{free}}$ 的精确几何、并把它分解为路线图，代价往往高得难以承受。因此，这类方法最适合自由度较少的机器人或低维规划问题。

### 路线图

路线图是嵌入在位形空间中的图 $\mathcal{G}=(\mathcal{V},\mathcal{E})$，其中每个顶点 $q\in\mathcal{V}$ 对应 $\mathcal{C}_{\mathrm{free}}$ 中的一个位形，每条边 $(q,q^{\prime})\in\mathcal{E}$ 表示相应位形之间的一条连续、无碰撞路径。令 $\mathcal{S}\subset\mathcal{C}_{\mathrm{free}}$ 表示 $\mathcal{G}$ 中顶点所代表的全部位形构成的集合。为使 $\mathcal{G}$ 成为有效的路线图，它必须满足两个关键条件，以保证准确表示 $\mathcal{C}_{\mathrm{free}}$ 的结构：

- 1. **可达性（accessibility）：** 从任意位形 $q\in\mathcal{C}_{\mathrm{free}}$ 出发，必须能简单地计算出一条到任意位形 $s\in\mathcal{S}$ 的连续、无碰撞路径。通常取 $s$ 为离 $q$ 最近的顶点（假定 $\mathcal{C}$ 是度量空间）。该条件确保自由空间中的每个位形都能在不离开 $\mathcal{C}_{\mathrm{free}}$ 的前提下连到路线图上。
- 2. **保持连通性（connectivity-preserving）：** 借助可达性条件，必须能把任意两个位形 $q_{\mathrm{S}},q_{\mathrm{G}}\in\mathcal{C}_{\mathrm{free}}$ 分别连接到路线图中的某两个 $s_{1},s_{2}$。保持连通性要求：若 $\mathcal{C}_{\mathrm{free}}$ 中存在从 $q_{\mathrm{S}}$ 到 $q_{\mathrm{G}}$ 的连续无碰撞路径，则路线图 $\mathcal{G}$ 中 $s_{1}$ 与 $s_{2}$ 之间也必须存在对应路径。换句话说，不会因为路线图未能捕捉自由空间底层的连通性而丢失 $\mathcal{C}_{\mathrm{free}}$ 中的可行路径。这一性质是组合式规划算法完备性的关键。

一旦满足这些条件，路线图就给出了规划问题的精确表示：顶点对应 $\mathcal{C}_{\mathrm{free}}$ 中可达区域内的代表位形，边编码它们之间的连通性。运动规划随之归结为图搜索问题：把起始位形与目标位形连到路线图上，在所得的图中搜索路径。

这一结构看起来可能与前面讨论的基于栅格的方法相似，关键区别在于空间的表示方式。路线图是为捕捉 $\mathcal{C}_{\mathrm{free}}$ 的真实几何与连通性而构造的，而不是把 $\mathcal{C}$ 强行离散到均匀栅格上。换句话说，路线图中的顶点可以对应自由空间内的**任意**位形，因此可行路径总能被保留在图表示中；而基于栅格的方法可能因为底层离散化过粗而无法表示某些合法路径。这种两步流程——先构造路线图、再做图搜索——为运动规划提供了有力而通用的框架［旁注：关于路线图概念的深入讨论，以及完备性与最优性要求的正式定义，请参阅 LaValle (2006)。］。

## 单元分解

如上所述，组合式方法必须构造一个精确编码规划问题的有限数据结构。实现这一点的一种途径是**单元分解**（cell decomposition）方法：把自由空间 $\mathcal{C}_{\mathrm{free}}$ 划分为有限个区域（称为**单元**（cell）），再用这些单元构造路线图。

理解单元分解的一个有用角度，是看使它适合运动规划的三个关键性质：

- 1. **单元内连通性平凡：** 在单元内部从一个位形到另一个位形计算路径必须容易。例如，若每个单元都是凸的，则单元内任意两点都可用一条仍位于 $\mathcal{C}_{\mathrm{free}}$ 中的直线段相连。
- 2. **可提取邻接关系：** 必须能直接判定哪些单元彼此相邻，从而通过连接相邻单元构造路线图。
- 3. **查询定位高效：** 对给定的起始位形与目标位形 $(q_{\mathrm{S}},q_{\mathrm{G}})$，应能高效确定它们分别位于哪些单元中。

满足这些条件后，运动规划问题就归结为图搜索问题：顶点对应对每个单元中的代表位形，边连接相邻单元。

### 垂直单元分解

二维环境中一种广泛使用的技术是**垂直分解**（vertical decomposition），也称**梯形分解**（trapezoidal decomposition）。假定障碍物是多边形的，令 $P$ 表示定义 $\mathcal{C}_{\mathrm{obs}}$ 的顶点集合。对每个顶点 $p\in P$，向上和向下沿垂直方向发出射线，穿过 $\mathcal{C}_{\mathrm{free}}$，直到与另一个障碍物或工作空间边界相交。依据局部几何的不同，会出现四种不同情形，分别对应垂直扩展可以向上、向下、双向或都不行，如图 4.9 所示。

![图 4.9：从多边形障碍物顶点垂直发出射线的四种一般情形。](/book-assets/motion-planning/_tikz__motion-planning-5.svg)

这一过程的结果如图 4.10 所示，是把 $\mathcal{C}_{\mathrm{free}}$ 分解为一组 2-单元（开梯形与退化三角形）与 1-单元（构成梯形之间边界的开垂直线段）。

分解就绪之后，就可以构造路线图 $\mathcal{G}=(\mathcal{V},\mathcal{E})$。对每个 2-单元 $C_{i}$，选一个代表采样点 $q_{i}\in C_{i}$——常用形心，不过具体取法并不关键。每个 1-单元也分配一个采样点。这些点在图 4.10 中显示为黑点。路线图图的定义如下：每个单元对应一个顶点；对每个 2-单元，添加边把它的采样点与其边界上相邻 1-单元的采样点相连。

按构造方式，可达性与连通性两个条件都得到满足：每个采样点都能通过其单元内的直线路径到达，任意两个相邻单元都在路线图中由一条边相连。因此路线图给出了规划问题的精确表示。一旦路线图构造完成，显式的单元分解就不再需要，规划归结为把 $q_{\mathrm{S}}$ 与 $q_{\mathrm{G}}$ 连到路线图上，并执行一次图搜索。

## 其他路线图构建方法

除单元分解之外，人们还发展了其他若干构造路线图的方法，它们往往利用自由空间的几何性质。

例如，**最大间隙路线图**（maximum clearance roadmap）试图与障碍物保持尽可能大的距离，实际上沿着自由空间的「骨架」前进。一个著名例子是**广义维诺图**（generalized Voronoi diagram），其路线图由 $\mathcal{C}_{\mathrm{free}}$ 中到至少两个障碍物等距的点构成。这类路线图的优点是产生的路径使安全裕度最大化，这对在狭窄或不确定环境中运行的机器人尤其有用。另一种做法是**最短路径路线图**（shortest path roadmap）：用避开障碍物的最短路径连接 $\mathcal{C}_{\mathrm{free}}$ 中的点对，以此构造路线图。关于这些及其他路线图构建技术的深入讨论，请参阅 LaValle (2006)［旁注：5. LaValle, S. M. *Planning Algorithms*. Cambridge University Press, 2006.］。每种路线图构建方式在计算容易程度、路径质量与鲁棒性之间提供了不同的折中。方法的选择取决于机器人与环境的几何特性，以及当前任务的需求。
# 基于采样的运动规划

组合法与栅格法的局限——尤其在高维空间中计算复杂度高——推动了**基于采样的运动规划**（sampling-based motion planning）算法的发展。在高层思路上，这类算法显式回避对 $\mathcal{C}_{\mathrm{free}}$ 与 $\mathcal{C}_{\mathrm{obs}}$ 的显式表示，转而依靠**随机采样**来刻画位形空间的结构。具体做法是把 $\mathcal{C}$ 空间中的随机采样与黑箱式的**碰撞检测**（collision detection）算法结合起来：后者判断某个位形或路径段是否无碰撞（即是否落在 $\mathcal{C}_{\mathrm{free}}$ 内）。通过逐步连接这些无碰撞样本，基于采样的方法能构建出一张路线图或一棵树结构，*在不显式表示自由空间的前提下*刻画其可行连通性，实践中带来显著的计算加速。这一范式有几方面优势：

- **概念简单**：算法相对易于理解与实现。
- **通用性**：同一框架适用于不同的机器人与环境。
- **可扩展性**：方法可以超出纯几何情形，处理运动动力学规划、微分约束与不确定性。

与此同时，基于采样的方法也有固有的局限。与精确的组合方法不同，它们对解的存在性或质量给出的保证通常更弱。此外，事先很难知道需要多少样本才能找到解，也很难保证只要存在解规划器就一定能找到。在理论层面，多数方法给出的是*概率*保证而非确定性保证：它们是**概率完备**（probabilistically complete）的（即若存在可行路径，则当样本数 $n$ 趋于无穷时找到它的概率趋于 1）；对某些变体还是**渐近最优**（asymptotically optimal）的（即若 $C_{n}$ 是 $n$ 个样本后所找到的最好路径的代价，$C^{\star}$ 是最优代价，则 $C_{n}$ 以概率 1 趋于 $C^{\star}$）。这两条性质本质上都是渐近的、概率的：它们不提供有限样本下的保证，只说明失败（或次优）的概率随 $n$ 增大而消失。这两条性质将在 4.4.3 节进一步讨论。

传统上，基于采样的运动规划算法分为两大流派：**概率路线图**（probabilistic roadmaps，PRM）与**快速探索随机树**（rapidly-exploring random trees，RRT）。PRM 是*多次查询规划器*（multi-query planner），其预计算结构可复用于同一环境中的多个规划问题。相比之下，RRT 是*单次查询规划器*（single-query planner），针对给定自由位形空间 $\mathcal{C}_{\mathrm{free}}$ 中特定的起点—目标对 $(q_{\mathrm{S}},q_{\mathrm{G}})$ 求一个解。尽管有这一区别，两类算法共享两个基本组件。第一个是碰撞检测例程 $\texttt{CollisionFree}(q)$，它判断位形 $q$ 是否落在自由空间 $\mathcal{C}_{\mathrm{free}}$ 内。第二个是局部规划器 $\texttt{LocalPlanner}(q,q^{\prime})$，它生成一小段路径——通常取位形空间中的直线段，或一段动力学可行的运动——并通过检查碰撞来验证其有效性。

下面概述 PRM 与 RRT，以及它们的理论性质与实践考量。

## 概率路线图（PRM）

PRM 是运动规划中最具影响力的基于采样的方法之一。在高层上，PRM 是一种多次查询规划器：它在位形空间中随机采样位形并把它们连成图，从而构建一张路线图。PRM 算法包含两个主要阶段：**构建阶段**（construction phase）与**查询阶段**（query phase）。构建阶段中，算法用均匀或带偏置的采样策略从 $\mathcal{C}_{\mathrm{free}}$ 中采样一组位形 $\{q_{1},q_{2},\ldots,q_{n}\}$，再用每个采样位形构建一张编码自由空间连通性的路线图。因此，路线图一旦构建完成，就可以通过把起点与目标位形接入路线图并运行一次图搜索，来求解同一环境中的多个规划问题。

形式上，PRM 算法可概括如下：

- **构建阶段**：
- （a）从 $\mathcal{C}$ 中采样 $n$ 个位形 $\{q_{1},q_{2},\ldots,q_{n}\}$，用碰撞检测方法 $\texttt{CollisionFree}(q)$ 剔除落在 $\mathcal{C}_{\mathrm{obs}}$ 中的样本。
- （b）按选定的连接规则在每一对位形 $q_{i}$ 与 $q_{j}$ 之间连边——例如二者距离小于某个阈值 $r$（即 $||q_{i}-q_{j}||\leq r$），*且* 局部规划器 $\texttt{LocalPlanner}(q_{i},q_{j})$ 在它们之间找到无碰撞路径（例如 $\mathcal{C}$ 空间中的直线段）。
- **查询阶段**：给定查询 $(q_{\mathrm{S}},q_{\mathrm{G}})\in\mathcal{C}_{\mathrm{free}}$，用局部规划器把 $q_{\mathrm{S}}$ 与 $q_{\mathrm{G}}$ 接到路线图中最近的节点上，然后用图搜索算法（如 Dijkstra 或 $A^{*}$）在路线图中找到从 $q_{\mathrm{S}}$ 到 $q_{\mathrm{G}}$ 的路径。

### 设计考量

PRM 的效果取决于若干关键设计决策，它们同时塑造其计算性能与刻画自由空间连通性的能力。首先要考虑的是采样策略。最直接的做法是在位形空间中均匀随机生成位形，只保留落在 $\mathcal{C}_{\mathrm{free}}$ 中的那些。这种做法覆盖无偏，但在以狭窄通道为主的环境中表现可能很差：这类区域体积小，因而很少被采到。为克服这一局限，人们提出了各种带偏置的采样策略，目标是提高在位形空间困难区域采样的概率。更一般地，启发式偏置策略可以把样本引向对特定规划任务可能更相关的区域，用均匀性换取复杂环境中的有效性。

另一项重要的设计选择是连接采样位形所用的方法。最常用的有两条规则：固定半径规则，即每个顶点尝试与半径 $r$ 的球内所有样本相连；以及 $k$ 近邻规则，即每个顶点与最近的 $k$ 个样本相连。本章余下部分会说明，这两条连接规则都有理论结果支撑，这些结果把 $r$ 与 $k$ 的取值同样本数与空间维数联系起来（例如见 Karaman and Frazzoli (2011)［旁注：6. Karaman, S., Frazzoli, E. “Sampling-based Algorithms for Optimal Motion Planning.” *Int. Journal of Robotics Research* 30(7), 846–894, 2011.］）。这些结果保证：随着样本数增长，路线图会变得足够连通，能够刻画 $\mathcal{C}_{\mathrm{free}}$ 的拓扑，而不会引入过多的样本。

### PRM 的特性

概率路线图框架特别适合在多次规划查询之间保持静态的环境。由于路线图的构建可能计算代价很高——主要开销在最近邻查询与碰撞检测——只有当预处理的投入能在同一工作空间的大量查询上摊销时，它才最有效。在这些场合，路线图充当可复用的数据结构，紧凑地编码自由空间的连通性，使查询能用标准图搜索算法快速得到答案。

正因如此，PRM 成为那些需要在高维但大体静态的环境中求解大量规划查询的领域的首选方法。它的长处不在于快速给出单个解，而在于构建一个可复用、刻画自由空间拓扑的结构，之后可反复用来高效求解大量查询。

总体而言，PRM 类运动规划算法在实践中被广泛认为能找到「好」路径，即使在高维位形空间中也是如此。但这可能需要大量昂贵的碰撞检测，因而带来可观的计算开销。

## 快速探索随机树（RRT）

RRT 是面向*单次查询*运动规划的基础性采样算法。与 PRM 的预计算思路不同，RRT 增量式地生长一棵树［旁注：树是一类特殊的图，连通且无环；换言之，树中任意两个顶点之间恰有一条路径。］——记为 $\mathcal{T}=(\mathcal{V},\mathcal{E})$——以初始位形 $q_{\mathrm{S}}$ 为根，设法把它连到指定的目标位形 $q_{\mathrm{G}}$。因此 RRT 特别适合只需解一次查询的场景，例如环境动态变化时。

RRT 迭代进行，每次迭代包含以下步骤：

- 从位形空间 $\mathcal{C}$ 中采样一个随机位形 $q_{\mathrm{rand}}$。
- 在合适的距离度量 $d(\cdot,\cdot)$（如欧氏距离）下，找到树 $\mathcal{T}$ 中距采样位形 $q_{\mathrm{rand}}$ 最近的顶点 $q_{\mathrm{near}}$。
- 从 $q_{\mathrm{near}}$ 朝 $q_{\mathrm{rand}}$ 方向移动，生成新位形 $q_{\mathrm{new}}$，并确保从 $q_{\mathrm{near}}$ 到 $q_{\mathrm{new}}$ 的运动无碰撞。
- 把 $q_{\mathrm{new}}$ 作为新顶点加入树 $\mathcal{T}$，并用边 $(q_{\mathrm{near}},q_{\mathrm{new}})$ 把它连到 $q_{\mathrm{near}}$。

算法持续扩展树，直到新增的顶点足够接近目标位形 $q_{\mathrm{G}}$［旁注：这种接近性可以这样验证：尝试把新增顶点连到目标，并检查该连接是否无碰撞；若成功，算法终止。］。此时通过回溯树即可提取从 $q_{\mathrm{S}}$ 到 $q_{\mathrm{G}}$ 的路径。若在 $N$ 次迭代的预算内仍未找到通向目标的可行连接，算法以失败终止。

### Voronoi 偏置

理解 RRT 效率的一个关键洞见，是用 Voronoi 图（Voronoi diagram）的视角来解读它的采样动力学（图 4.13）。树 $\mathcal{T}$ 中的每个顶点都在位形空间中定义一个 Voronoi 胞腔，由所有到该顶点比到其他顶点更近的点组成。由于随机样本均匀分布，扩展某个给定顶点的概率正比于其 Voronoi 胞腔的体积。位于树前沿的顶点往往拥有较大的胞腔，因而更可能被选中扩展。这种*Voronoi 偏置*（Voronoi bias）隐式地把树向外驱动，快速探索尚未覆盖的区域，而无需任何显式的前沿选择机制。

![图 4.13：RRT 中的 Voronoi 偏置。](/book-assets/motion-planning/figs__ch05_figs__voronoi.png)

总体而言，RRT 为单次查询运动规划提供了强大的框架。具体来说，RRT 类运动规划算法在实践中被广泛使用，因为它们能在高维空间中快速找到可行路径。但 RRT 产生的路径往往次优。它的扩展——特别是 RRT∗ 及其变体——把 RRT 的探索能力与可证明的最优性保证结合起来，因而在实际应用中被广泛采用。重要的是，RRT（以及 PRM）不需要对 $\mathcal{C}_{\mathrm{free}}$ 做显式刻画，这正是它能扩展到更高维 $\mathcal{C}$ 空间的关键。

## 理论保证

PRM 与 RRT 都带有理论保证，这些保证支撑了它们在运动规划任务中的有效性。具体来说，我们考虑两条关键性质，它们形式化了 PRM、RRT 及其相关扩展 PRM∗ 与 RRT∗ 在采样预算很大时「成功」的含义：*概率完备性*与*渐近最优性*。

### 概率完备性

若只要存在可行路径，算法找不到可行路径的*概率*就随样本数 $n$ 趋于无穷而趋于零，则称该规划器**概率完备**。在对位形空间与采样过程的合理假设下［旁注：直观地说，采样分布必须给自由空间的每个开子集赋予非零概率。］，PRM 与 RRT 都满足概率完备性。

深入讨论概率完备性超出本章范围，可参阅 Kavraki et al. (1996)［旁注：7. Kavraki, L. E., Svestka, P., J.-C. Latombe, Overmars, M. H. “Probabilistic roadmaps for path planning in high-dimensional configuration spaces.” *IEEE Transactions on Robotics and Automation* 12(4), 566–580, 1996.］与 LaValle (1998)［旁注：8. LaValle, S. M. *Rapidly-Exploring Random Trees: A New Tool for Path Planning*. 1998.］，它们为 PRM、RRT 及相关算法建立了这些保证。

### 渐近最优性

若当样本数 $n$ 趋于无穷时，算法所找到的最好路径的代价收敛到最优代价的*概率*趋于 1，则称该规划器**渐近最优**。要获得渐近最优性，必须仔细控制底层随机图的连通性。连接过稀，图可能无法包含接近最优的路径；连接过密，计算开销可能显著上升。因此，渐近最优性的保证依赖于选择恰当的连接半径，使其随样本数按合适的速率减小，以平衡这两种相互竞争的影响。

Karaman and Frazzoli (2011)［旁注：9. Karaman, S., Frazzoli, E. “Sampling-based Algorithms for Optimal Motion Planning.” *Int. Journal of Robotics Research* 30(7), 846–894, 2011.］首次对基于采样的规划器的渐近最优性做了严格研究。特别地，他们针对 PRM∗ 证明了如下结果：

:::thm 定理 4.1
若连接半径 $r(n)$ 满足：

$$
r(n)\geq\gamma\left(\frac{\log n}{n}\right)^{1/d},
$$

其中 $d$ 是位形空间的维数，$\gamma$ 是只依赖于 $d$ 与 $\mathcal{C}_{\mathrm{free}}$ 的常数，则 $PRM^{*}$ 在 $n$ 个样本后返回的最好路径的代价当 $n\to\infty$ 时*以概率一*收敛到最优代价。
:::

Karaman and Frazzoli (2011)［旁注：10. Karaman, S., Frazzoli, E. “Sampling-based Algorithms for Optimal Motion Planning.” *Int. Journal of Robotics Research* 30(7), 846–894, 2011.］还引入了 RRT 的渐近最优变体 RRT∗，它加入重连（rewiring）步骤，随时间不断改进路径质量。

## 快速行进树算法（FMT∗）

*快速行进树*（Fast Marching Tree，FMT∗）算法由 Janson et al. (2015)［旁注：11. Janson, L., Schmerling, E., Clark, A., Pavone, M. “Fast Marching Tree: A Fast Marching Sampling-Based Method for Optimal Motion Planning in Many Dimensions.” *Int. Journal of Robotics Research* 34(7), 883–921, 2015.］提出，是基于采样的运动规划器家族中较新的成员。它的核心贡献在于：像 PRM∗ 与 RRT∗ 一样达到渐近最优，同时执行的碰撞检测次数大幅减少——而碰撞检测往往是运动规划中的计算瓶颈。

### 高层描述

FMT∗ 在一组固定的 $n$ 个来自 $\mathcal{C}_{\mathrm{free}}$ 的无碰撞样本上工作，再加上初始条件 $q_{\mathrm{S}}$，即 $V=\{q_{\mathrm{S}}\}\cup\{q_{1},\dots,q_{n}\}\subset\mathcal{C}_{\mathrm{free}}$。它既不试图构建全局路线图（如 PRM∗），也不通过随机采样扩展树（如 RRT∗），而是*同时*进行图构建与图搜索。每次迭代，它在*到达代价空间*（cost-to-arrive space）中把当前树向外扩展：总是从树中代价最低的节点出发，通过当前最好的一步连接把它连到附近未访问的样本上。这一思路与 Dijkstra 算法以及求解程函方程（Eikonal equation）的快速行进法（Fast Marching Method）类似［旁注：25. Sethian, J. A. “A fast marching level set method for monotonically advancing fronts.” *Proceedings of the National Academy of Sciences* 93(4), 1591-1595, 1996.］，树中已扩展的节点无需再次访问。

在算法的任一时刻，样本集 $V$ 被划分为三个互不相交的子集：(i) $V_{\mathrm{open}}$，当前属于树且可被扩展的节点；(ii) $V_{\mathrm{unvisited}}$，尚未连到树的样本；(iii) $V_{\mathrm{closed}}$，已扩展因而排除在后续连接之外的节点。初始时 $V_{\mathrm{open}}=\{q_{\mathrm{S}}\},V_{\mathrm{unvisited}}=V\setminus\{q_{\mathrm{S}}\},\text{and}\,V_{\mathrm{closed}}=\emptyset$。每次迭代中，算法取出 $V_{\mathrm{open}}$ 中代价最低的节点 $q^{\prime}$，并考察距 $q^{\prime}$ 半径 $r_{n}$ 内的所有未访问邻居 $q\in V_{\mathrm{unvisited}}$。对每个这样的 $q$，计算使代价最小的最优父节点 $q_{p}\in V_{\mathrm{open}}$：

$${#eq4.6}
q_{p}^{\ast}=\operatorname*{arg\,min}_{q_{p}\in\mathcal{N}_{V_{\mathrm{open}}}%
(q)}\Big{[}C(q_{p})+c(q_{p},q)\Big{]},
$$

其中 $C(q_{p})$ 是到达 $q_{p}$ 的代价，$c(q_{p},q)$ 是局部路径代价，$\mathcal{N}_{V_{\mathrm{open}}}(q)$ 表示 $q$ 在 $V_{\mathrm{open}}$ 的样本中的邻居集合。关键在于，只有这条最优候选边 $(q_{p}^{\ast},q)$ 会被碰撞检测。若该边可行，$q$ 就被加入树，并从 $V_{\mathrm{unvisited}}$ 移入 $V_{\mathrm{open}}$。处理完 $q^{\prime}$ 的所有邻居后，$q^{\prime}$ 从 $V_{\mathrm{open}}$ 移入 $V_{\mathrm{closed}}$。该过程重复，直到目标区域中有节点被加入树，或 $V_{\mathrm{open}}$ 变为空。

FMT∗ 的效率来自它的*惰性*（lazy）评估策略：每个候选节点只对一条边做碰撞检测，而不是像 PRM∗ 那样检测所有可能的边。这种惰性偶尔可能丢弃更好的边，但随样本数增加，这类事件发生的概率趋于零。事实上，FMT∗ 是渐近最优的：当 $n$ 趋于无穷时，它返回的最好路径的代价*以概率一*收敛到最优代价。效率提升相当可观：与 PRM∗ 相比，FMT∗ 的碰撞检测次数之比趋于零，这使它特别适合碰撞检测主导计算的高维问题。

在这个意义上，FMT∗ 处在 PRM∗ 与 RRT∗ 之间的自然中间位置。与 PRM∗ 一样，它从一组预先采样好的固定位形出发；但它不构建全局路线图，而是把节点增量式地连成一棵以起点为根的树。与 RRT∗ 一样，它构建单棵树，但它的扩展方式能带来更有效的探索，解的质量往往也更好。

## 运动动力学规划

到目前为止介绍的几何运动规划算法都假定机器人运动不受微分约束。这一假设简化了规划任务，因为它允许把问题分解为两步：先计算一条忽略动力学的无碰撞路径，再对该路径做平滑或重参数化，使机器人能够跟踪它，如第 3 章所述。然而，纯几何的计划并不总能直接细化为动力学可行、经过优化的轨迹，往往需要下游的轨迹优化器或控制器做出激进的修正。

*运动动力学运动规划问题*（kinodynamic motion planning problem）通过显式考虑机器人动力学来扩展几何运动规划。形式上，令 $\mathcal{X}\subseteq\mathbb{R}^{n}$ 与 $\mathcal{U}\subseteq\mathbb{R}^{m}$ 分别表示机器人系统的状态空间与控制空间，并考虑如下形式的动力学：

$${#eq4.7}
\dot{\bm{x}}(t)\;=\;f(\bm{x}(t),\bm{u}(t)),\qquad\bm{x}(t)\in\mathcal{X},\;\bm%
{u}(t)\in\mathcal{U}.
$$

与几何规划一样，机器人的位形 $q$ 可以从完整的动态状态 $\bm{x}$ 导出，后者既编码位置，也编码碰撞检测所需的信息。运动动力学规划问题于是要求把机器人从初始状态 $\bm{x}_{\mathrm{init}}$ 驱动到目标区域 $\mathcal{X}_{\mathrm{goal}}$，同时满足避碰与系统动力学约束。

把运动学与动力学约束嵌入规划阶段后，规划器产生的名义运动在构造上就是动力学可行的。这反过来为轨迹优化提供了更好的初值，也减轻了跟踪控制器的负担，最终提升系统在执行时的整体性能。

这一表述凸显了几何规划与运动动力学规划的根本区别。几何规划中，可行路径是位形空间里任意无碰撞曲线；运动动力学规划则把容许轨迹限制为与系统运动方程一致的那些。例如，轮式机器人不能横向移动，四旋翼不能凭惯性瞬间停住。这些微分约束极大地改变了搜索空间，如图 4.14 所示：加入动力学约束会显著压缩可行轨迹集合。

![图 4.14：几何规划与运动动力学规划的比较。障碍物是实心多边形/圆（上排）与实心直线段（下排），基于采样的规划器所考虑的运动会树在整个位形空间中给出，解轨迹用高亮标出。每一行中机器人的起止位形相同，但右图加入微分约束后极大限制了可能的运动，使规划问题明显更难。上排中，强制简单车动力学使车辆不能侧向滑动（b），因此轨迹比几何情形（a）更复杂。下排中，通过简化的四旋翼动力学引入动量后，轨迹比几何情形（c）更平滑但更绕（d），反映了车辆惯性带来的约束。[图取自 Schmerling and Pavone (2019)［旁注：12. ### 基于前向传播的算法

把动力学纳入基于采样的规划器，一种实用途径是*前向传播*（forward propagation）。规划器不直接连接采样得到的状态，而是采样一个控制输入 $\bm{u}\in\mathcal{U}$ 与一个时长 $t$，再把系统动力学向前积分，得到新状态。例如，RRT 的运动动力学扩展按如下步骤进行：(i) 采样一个随机状态，并在树中找到它的最近邻 $q_{\mathrm{near}}$；(ii) 采样随机控制 $\bm{u}\in\mathcal{U}$ 与传播时间 $t$；(iii) 从 $q_{\mathrm{near}}$ 出发向前仿真系统，得到新状态。若所得轨迹段无碰撞，就把它加入树，否则丢弃。值得注意的是，在对 $f(\bm{x}(t),\bm{u}(t))$ 的温和正则性假设下，带前向传播的 RRT 变体已被证明是概率完备的。

运动动力学规划因而在单一框架内统一了避障与微分约束，这对机器人学尤为重要：动力学考量会大幅限制可行路径集合，例如在高速地面车辆、空中机器人或具有显著动量的系统中。

## 概率规划器必须是随机的吗？

一个自然的问题是：基于采样算法的成功，是否从根本上依赖于采样过程的随机性？具体地说，若把 PRM∗ 或 FMT∗ 这类算法*去随机化*（de-randomized），即在确定性样本上运行，它们的理论保证与实践性能是否仍然成立？

这个问题之所以重要，有几方面原因。确定性采样序列能消除概率不确定性，从而大幅简化安全关键系统中的认证。它们还能让规划器更有效地利用离线计算，并简化最近邻搜索等操作。

近期结果表明答案是肯定的：只要精心选择低散布（low-dispersion）的确定性采样序列，渐近最优性与完备性保证都能保留［旁注：26. Janson, L., Schmerling, E., Clark, A., Pavone, M. “Deterministic sampling-based motion planning: Optimality, complexity, and performance.” *Int. Journal of Robotics Research* 37(1), 46-61, 2018.］。因此，随机性对正确性与性能都不是严格必需的。概率采样提供了便利与通用性，而确定性低散布序列能给出同样强的保证，并在可预测性、效率与易于认证方面具有优势。

# 势场法

前面几节介绍的规划方法着眼于用紧凑的图结构刻画机器人自由空间的全局连通性，再在图上搜索可行路径。相比之下，本节介绍的方法基于一种根本不同的思路。势场法［旁注：27. Khatib, O. “Real-Time Obstacle Avoidance for Manipulators and Mobile Robots.” *The International Journal of Robotics Research* 5(1), 90-98, 1986.］用物理学启发的类比来表述运动规划问题：把机器人看作在定义于位形空间上的*人工势场*（artificial potential field）作用下运动的粒子。该势场被构造成既把机器人引向目标、又把它推离障碍物，从而产生一条平滑连续的路径，如图 4.15 所示。

![图 4.15：二维位形空间中的势场。引力势（左上）在目标处形成吸引盆。斥力势（右上）在障碍物周围形成势垒。合成势场（左下）定义了一张曲面，其负梯度把机器人从起点引向目标，从而得到平滑的轨迹（右下）。](/book-assets/motion-planning/figs__ch05_figs__potential_field.png)

这一方法的核心是设计人工势函数 $U(q):\mathcal{C}\to\mathbb{R}$，它通常由两部分组成：把机器人拉向目标位形 $q_{\mathrm{goal}}$ 的*引力势*（attractive potential）$U_{\mathrm{att}}(q)$，以及把它推离障碍物的*斥力势*（repulsive potential）$U_{\mathrm{rep}}(q)$：

$${#eq4.8}
U(q)=U_{\mathrm{att}}(q)+U_{\mathrm{rep}}(q).
$$

机器人的运动则由沿总势场的负梯度 $-\nabla U(q)$ 前进确定，该方向是势场中最速下降的方向。具体来说，位形 $q$ 处作用于机器人的等效力为：

$${#eq4.9}
\begin{split}F(q)=-\nabla U(q)&=-\nabla U_{\mathrm{att}}(q)-\nabla U_{\mathrm{%
rep}}(q)\\
&=-F_{\mathrm{att}}(q)-F_{\mathrm{rep}}(q),\end{split}
$$

其中 $F_{\mathrm{att}}(q)$ 与 $F_{\mathrm{rep}}(q)$ 分别是*引力*与*斥力*。路径的生成方式是：从初始位形 $q_{\mathrm{S}}$ 出发，沿该力方向反复小步移动，相当于在势面上做梯度下降，直到到达目标位形 $q_{\mathrm{G}}$。

下面介绍引力势与斥力势的常用选择；更全面的势场法论述可参阅 Latombe (1991)［旁注：13. Latombe, J. C. *Robot Motion Planning*. Kluwer Academic Publishers, 1991.］。

### 引力势

引力势的作用是在目标位形周围形成吸引盆——理想情况下是唯一的全局极小——引导机器人朝它运动。引力势的一个常用选择是如下抛物型函数：

$${#eq4.10}
U_{\mathrm{att}}(q)=\frac{1}{2}k_{\mathrm{att}}\,\rho^{2}(q,q_{\mathrm{G}}),
$$

其中 $k_{\mathrm{att}}$ 是正的比例因子，$\rho(q,q_{\mathrm{G}})$ 表示当前位形 $q$ 与目标位形 $q_{\mathrm{G}}$ 之间的距离度量（如欧氏距离）。因此 $U_{\mathrm{att}}(q)$ 非负，并在 $q_{\mathrm{G}}$ 处取最小值，此时 $U_{\mathrm{att}}(q_{\mathrm{G}})=0$。

所得的引力（指向目标）为：

$${#eq4.11}
\begin{split}F_{\mathrm{att}}(q)&\coloneqq-\nabla U_{\mathrm{att}}(q)\\
&=-k_{\mathrm{att}}\,\rho(q,q_{\mathrm{G}})\nabla\rho(q,q_{\mathrm{G}})\\
&=-k_{\mathrm{att}}(q-q_{\mathrm{G}}),\\
&\text{where }\rho(q,q_{\mathrm{G}})=||q-q_{\mathrm{G}}||\text{ and }\nabla%
\rho(q,q_{\mathrm{G}})=\frac{q-q_{\mathrm{G}}}{||q-q_{\mathrm{G}}||},\end{split}
$$

它是到目标距离的线性函数。

### 斥力势

斥力势的作用是在障碍物周围形成势垒，防止机器人与其碰撞。此外，它的影响范围应当有限，只在机器人距障碍物一定距离之内才起作用。实现这两点的一种方式是如下定义斥力势：

$${#eq4.12}
U_{\mathrm{rep}}(q)=\begin{cases}\frac{1}{2}k_{\mathrm{rep}}\left(\frac{1}{%
\rho(q,\mathcal{C}_{\mathrm{obs}})}-\frac{1}{\rho_{0}}\right)^{2}&\text{if }%
\rho(q,\mathcal{C}_{\mathrm{obs}})\leq\rho_{0},\\
0&\text{if }\rho(q,\mathcal{C}_{\mathrm{obs}})>\rho_{0},\end{cases}
$$

其中 $k_{\mathrm{rep}}$ 是正的比例因子，$\rho(q,\mathcal{C}_{\mathrm{obs}})$ 表示位形 $q$ 到位形空间中最近障碍物的距离，$\rho_{0}$ 是超过之后斥力势不再起作用的阈值距离，也称为*影响距离*（distance of influence）。形式上，到最近障碍物的距离定义为：

$${#eq4.13}
\rho(q,\mathcal{C}_{\mathrm{obs}})=\min_{q^{\prime}\in\mathcal{C}_{\mathrm{obs%
}}}\rho(q,q^{\prime}),
$$

其中 $\mathcal{C}_{\mathrm{obs}}$ 是会导致与障碍物碰撞的位形集合。

若 $\mathcal{C}_{\mathrm{obs}}$ 是凸区域，则 $\rho(q,\mathcal{C}_{\mathrm{obs}})$ 在 $\mathcal{C}_{\mathrm{free}}$ 中处处可微，相应的斥力为：

$${#eq4.14}
\begin{split}F_{\mathrm{rep}}(q)&\coloneqq-\nabla U_{\mathrm{rep}}(q)\\
&=\begin{cases}k_{\mathrm{rep}}\left(\frac{1}{\rho(q,\mathcal{C}_{\mathrm{obs}%
})}-\frac{1}{\rho_{0}}\right)\frac{1}{\rho^{2}(q,\mathcal{C}_{\mathrm{obs}})}%
\nabla\rho(q,\mathcal{C}_{\mathrm{obs}})&\text{if }\rho(q,\mathcal{C}_{\mathrm%
{obs}})\leq\rho_{0},\\
0&\text{if }\rho(q,\mathcal{C}_{\mathrm{obs}})>\rho_{0}.\end{cases}\end{split}
$$

具体来说，设 $q_{\mathrm{obs}}^{\ast}$ 是障碍物边界上距 $q$ 最近的点，即 $q_{\mathrm{obs}}^{\ast}=\arg\min_{q^{\prime}\in\mathcal{C}_{\mathrm{obs}}}\rho(q,q^{\prime})$。那么梯度 $\nabla\rho(q,\mathcal{C}_{\mathrm{obs}})$ 是指离 $\mathcal{C}_{\mathrm{obs}}$ 的单位向量，方向沿连接 $q_{\mathrm{obs}}^{\ast}$ 与 $q$ 的线段。

### 优缺点

势场法的主要优点是简单且计算高效。这些方法最初是作为移动机器人的在线避障策略提出的［旁注：28. Khatib, O. “Real-Time Obstacle Avoidance for Manipulators and Mobile Robots.” *The International Journal of Robotics Research* 5(1), 90-98, 1986.］，适用于障碍物可能事先未知的动态环境。它不需要在图上做复杂搜索，也不需要构建路线图：路径生成只需在机器人当前位形处评估势函数及其梯度。

然而，由于势场规划器本质上是在势函数上做梯度下降，它们容易陷入局部极小。具体来说，规划器可能被困在引力与斥力相互平衡的区域：某个并非目标的位形处合力为零。这一问题常见于含凹形障碍物的环境（例如 U 形陷阱），或狭窄走廊中相对墙壁的斥力抵消了指向目标的引力。因此，标准势场规划器不是*完备*的，即使存在路径也可能找不到。

为解决局部极小问题，人们提出了多种技术。一种做法是引入随机「抖动」（例如对机器人位形施加小的随机扰动）以逃出局部极小的吸引盆。更有理论依据的方案是构造称为*导航函数*（navigation function）的特殊势场，可证明除目标外不含局部极小［旁注：29. Rimon, E. *Exact robot navigation using artificial potential functions. PhD Thesis*. Yale University, 1990.］。但构造这类函数计算代价高，一般只对简单环境可行。另一种相关方法是*波前规划器*（wavefront planner）或*刷火算法*（brushfire algorithm）：它把位形空间离散化（类似栅格法），从目标向外传播一个势波，从而在栅格上生成保证无局部极小的势场。

总之，势场法为局部运动规划与避障提供了快速、反应式的框架。其简单性有吸引力，但由于局部极小问题导致全局规划不可靠，这限制了它作为独立的完备运动规划器的使用。

# 本章小结

本章把运动规划介绍为把高层任务规范转成可行、无碰撞路径的关键环节。我们把核心问题表述为：寻找一串动作，把机器人从起始位形驱动到目标位形，同时避开障碍物。贯穿全章的一条主线是把运动抽象到机器人的位形空间（$\mathcal{C}$ 空间）中，在那里规划归结为在自由空间 $\mathcal{C}_{\mathrm{free}}$ 中寻找一条连续路径。

我们先讨论了*栅格法*（grid-based methods），它把位形空间离散化，把问题转化为图上的最短路搜索。由此引入了一族通用的标签修正（label-correcting）算法，包括求最短路的 Dijkstra 算法，以及它的有信息扩展 A∗——后者用启发函数把搜索高效地引向目标。接着转向*组合规划*（combinatorial planning），这是一种精确方法，通过把连续自由空间分解为简单单元来构造路线图，能保证完备性，但在高维空间中面临计算挑战。随后讨论了*基于采样的方法*，它们依靠随机采样与碰撞检测来增量式地构建 $\mathcal{C}_{\mathrm{free}}$，从而避免显式构造自由空间。我们介绍了 PRM 算法——构建自由空间可复用图的多次查询规划器，以及单次查询的 RRT 算法——从起始位形增量式生长一棵树。我们总结了它们的关键理论性质，包括概率完备性与渐近最优性，这些性质催生了 PRM∗、RRT∗ 与 FMT∗ 等更先进的规划器。我们进一步把这些概念扩展到*运动动力学规划*，它纳入系统动力学；并讨论了确定性低散布采样如何能提供与概率方法相当的理论保证，同时在可预测性与认证方面带来好处。最后介绍了*势场法*，它通过定义人工势函数把机器人引向目标、推离障碍物来生成路径，能实现快速、反应式的局部规划，代价是可能出现局部极小。

# 习题 1：A∗ 运动规划

本习题中，你要为若干简单二维环境实现基于栅格的 A∗ 运动规划算法。在文件 `ch04/exercises/a_star.ipynb` 与 `ch04/exercises/a_star.py` 中，实现 A∗ 算法的关键部分（见算法 2），在若干随机生成的路径规划问题上运行该算法，然后探索一种平滑所得离散路径的方法——这在实际机器人运动规划任务中很有用。

```
Data: start node q_S, goal node q_G
Result: shortest path from q_S to q_G (if reachable)

O ← {q_S}                       /* initialize open set */
C ← {}                          /* initialize closed set */
C(q_S) ← 0                      /* initialize cost-to-arrive */
C̃(q_S) ← distance(q_S, q_G)     /* initialize estimated cost */

while O is not empty do
    q ← lowest_est_cost_through(O)
    if q = q_G then
        return reconstruct_path()
    O.remove(q)
    C.add(q)
    for q′ ∈ free_neighbors(q) do
        if q′ ∈ C then
            continue
        if q′ ∉ O then
            O.add(q′)
        else if C(q) + distance(q, q′) > C(q′) then
            continue
        parent(q′) ← q
        C(q′) ← C(q) + distance(q, q′)
        C̃(q′) ← C(q′) + distance(q′, q_G)

return Failure
```

在本 A∗ 实现中，我们用一张图表示自由空间，通过在确定性栅格上采样状态并做碰撞检测来遍历这张图。这种实现可归类为有信息的确定性采样规划（「有信息」源自 A∗ 的启发函数）。

- 在 `a_star.py` 的 `Astar` 类中实现其余函数。这些函数对应运动规划算法中许多关键的功能模块：
- `is_free`：检查某个状态是否无碰撞且有效。
- `distance`：计算两点之间的行进距离。
- `get_neighbors`：找出给定状态的自由邻居状态。
- `solve`：运行 A∗ 运动规划算法。

注意：我们对状态做碰撞检测，但不检测边。这能省下一些计算（碰撞检测往往是运动规划中最昂贵的操作之一）。此外，本例中障碍物与栅格对齐，因此路径仍会保持无碰撞。但在这种特殊情形之外，应加入边碰撞检测和/或膨胀障碍物，以保证避碰。

- 对真实机器人（它必须跟踪轨迹）而言，在栅格上规划出的路径往往并不理想。本习题中，我们通过对路径节点拟合三次样条来平滑 A∗ 的路径。请在 `a_star.ipynb` 的 `compute_smooth_plan` 函数中实现。

注意：确保平滑后的解无碰撞有很多办法（例如对平滑后的路径做碰撞检测，并对平滑参数做二分搜索以找到紧贴障碍物的拟合；或在原规划中膨胀障碍物，为平滑留出额外空间）。这一策略同样可用于几何的基于采样的规划方法。

# 习题 2：快速探索随机树

本习题中，你要实现基于采样的 RRT 运动规划算法，在简单二维环境中规划路径。在文件 `ch04/exercises/rrt.ipynb` 与 `ch04/exercises/rrt.py` 中，实现 RRT 算法的关键部分，并定义一个利用节点间简单直线连接的 `GeometricRRT` 规划器。

在本 RRT 实现中，我们考虑「几何」RRT 问题，即节点之间用简单直线连接。

```
Data: start node q_S, goal node q_G, max iterations N_max, goal sampling bias α
Result: path from q_S to q_G (if reachable)

T ← {q_S}                       /* initialize tree */

for k ← 1 to N_max do
    if rand() < α then
        q′ ← q_G
    else
        q′ ← random_sample()
    q ← nearest_neighbor(q′, T)
    q′ ← steer_towards(q, q′)
    if is_free_motion(q, q′) then
        parent(q′) ← q
        T.add(q′)
        if q′ = q_G then
            return reconstruct_path()

return Failure
```
