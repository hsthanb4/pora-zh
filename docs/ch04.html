第 4 章 · Motion Planning

运动规划

如第 2 章与第 3 章所述，自主系统通过一个从战略决策到实时控制的过程层次，把高层目标转化为具体的物理动作。开环轨迹优化为生成动态可行的状态序列与控制序列提供了有原则的框架，但它往往难以处理复杂的、依赖状态的约束，例如避碰。此外，轨迹优化方法通常只给出局部最优解，其质量强烈依赖初始化，可能无法捕捉问题的全局结构。

为应对这些局限，本章聚焦运动规划（motion planning），它采取更全局的视角，显式推理环境约束、障碍物与轨迹可行性的整体。为保持计算可处理性，运动规划通常依赖简化的动力学模型，给出粗粒度或几何形式的路径，以保证无碰撞导航。实践中，运动规划与轨迹优化往往互补：运动规划通过找到一条初始无碰撞路径来确立全局可行性，轨迹优化再把这条路径细化为平滑、动态一致且经过优化的轨迹。

运动规划问题在 1970 年代被形式化定义，其研究历史相当丰富。1980 年代的早期工作聚焦于精确的组合式算法，力求以数学的严格性刻画位形空间的几何。这些方法在理论上优雅，但在高维问题上遭遇严重的计算瓶颈。1990 年代随着采样方法的引入出现了范式转变，为复杂的运动规划问题提供了可扩展的解法。2000 年代，规划算法被大规模部署到实时系统上，从自动驾驶汽车到机械臂。今天，运动规划研究依然活跃并不断扩展，关注融合微分约束与逻辑约束、不确定性下的规划、利用并行计算，以及引入基于学习的方法。

运动规划的重要性体现在其应用的广度上。仅举几例：在自动驾驶中，规划算法为在密集车流中行驶的车辆计算安全高效的机动动作；在人形机器人中，规划器为行走、攀爬或在杂乱环境中操作等任务协调全身运动；在手术机器人中，运动规划用于设计在人体内部精确、无碰撞的工具轨迹。即使在经典机器人之外，运动规划技术也已在蛋白质折叠等领域找到应用——需要在高维位形空间中穿行，以确定蛋白质的折叠路径。

过去几十年里，人们发展出多种算法来求解运动规划问题。这些方法通常归为四大类：基于栅格的规划、组合式规划、基于采样的规划与势场法。概括地说，基于栅格的规划器把机器人的环境离散为栅格，并用图搜索算法在栅格单元中计算一条可行路径。组合式规划器构造位形空间的显式表示，刻画规划所需的自由空间的连通性。基于采样的规划器利用随机采样与碰撞检测逐步探索位形空间，对显式表示变得不可行的高维问题具备可扩展性。最后，势场法构造人工势函数，把机器人吸向目标，同时把它推离障碍物。

本章先在第 4.1 节形式化定义运动规划问题，引入核心概念与记号。随后讨论上述四大类算法范式，即第 4.2 节的基于栅格的规划、第 4.3 节的组合式规划、第 4.4 节的基于采样的规划，以及第 4.5 节的势场法。

我们先给出运动规划问题最基本的形式化定义。令 表示机器人的工作空间（workspace），即机器人所处的物理环境。工作空间内存在已知的障碍区域 ，其边界为多边形（分段线性）。机器人本身建模为一个刚性多边形，必须在工作空间中穿行而不与任何障碍物相交注对三维工作空间，唯一的差别是 ，且机器人与障碍区域用多面体表示。注这里给出的基本表述可以远远超出刚性多边形与多面体的范围，推广到几何形状复杂的机器人。关于这些推广的深入讨论，请参阅 LaValle (2006)。。

基于栅格的运动规划

简化运动规划问题的一种自然做法，是把机器人连续的位形空间离散成栅格。我们不再推理无穷多个可能位形，而是把环境划分为有限个单元来近似。每个单元被分类为自由（即无碰撞，机器人可以占据）或禁行（即会导致与障碍物碰撞）。机器人可以在相邻的自由单元之间移动，规划任务就归结为找一串连通的自由单元，从起点通向目标。

这种离散化自然地把运动规划转化为图搜索问题。具体来说，栅格中的每个自由单元表示为图中的一个顶点，当两个单元相邻且都自由时，就在对应顶点之间加一条边。形式上，我们构造图 ，其中每个顶点 对应一个自由单元，每条边 对应机器人在相邻单元之间的一次合法移动。于是规划就变成在图中找一条从起始顶点到目标顶点的路径。

这一视角很有力，因为它让运动规划可以借用图论与计算机科学数十年的成果。原本用于求解最短路问题的算法——如广度优先搜索或 Dijkstra 算法——可以直接用于运动规划。换句话说，「在带障碍物的空间中穿行」这个看似几何的问题，被归约为「在图中找一条路径」这个纯组合问题。不过这种做法依赖于对 的显式刻画，而构造栅格、把每个单元分类为自由或占据正需要这一刻画。实践中获得这种精确刻画往往不可行——尤其在高维位形空间中——因此需要其他策略，例如本章后面讨论的基于采样的规划。

标签修正算法

一旦运动规划问题被表述为图搜索，下一步就是设计一个系统地探索该图、寻找从起点到目标路径的算法。用于此任务的一大类强有力方法称为标签修正算法（label-correcting algorithm）。

「标签」一词指的是与图中每个顶点关联的一个数值，表示从起始顶点到该顶点目前已知的最佳路径代价。概括而言，标签修正算法通过迭代改进这些代价标签来推进。初始时只有起始顶点的代价标签为零，其余全部初始化为无穷（或未定义状态）。算法在探索图的过程中，一旦发现通往某个顶点更好（代价更低）的路径，就更新——也就是修正——相应的标签。

选择规则的作用

选择下一个要扩展的顶点所用的选择规则，是区分各种标签修正算法的关键因素之一，最终决定了它们的效率与性能。若干经典搜索方法都可以看作标签修正框架的特例，例如：

  • 深度优先搜索（DFS）： 在 DFS 中（图 4.5），前沿按栈（后进先出）管理。这意味着算法总是沿着最近发现的路径继续深入，然后才回溯。DFS 的吸引力在于简单、内存占用低——活跃节点数正比于搜索深度。但 DFS 有陷入搜索树中深而无用分支的风险，导致寻找最短路径的性能很差。
  • 广度优先搜索（BFS）： 在 BFS 中（图 4.6），前沿是一个队列（先进先出）。算法先扩展给定「深度」上的所有节点，再进入下一层，从而以环绕起始节点的同心层方式探索图。与 DFS 相比，BFS 需要多得多的内存，因为它必须存下某一深度上的所有前沿节点。
  • Dijkstra 算法（也称最佳优先搜索）： 在 Dijkstra 算法中（算法 4.2），前沿是按暂定标签 （即目前找到的最佳到达代价）排序的优先队列。每次迭代选取标签最小的顶点进行扩展。形式上，把这种对下一个顶点的贪心选择写成：

基于栅格规划的优缺点

基于栅格的规划方法有几个吸引人的优点，这解释了它们在机器人领域长期流行的原因。也许最重要的好处是简单：把位形空间离散为单元、把规划当作图搜索问题来处理，这一基本想法易于实现也易于推理。一旦栅格构造完成，DFS、BFS 或 Dijkstra 等经典搜索算法就可以直接应用。这也使基于栅格的方法在某些情形下相对快速，尤其是当栅格分辨率与环境尺度、障碍物复杂度匹配得当时。

尽管有这些优点，基于栅格的方法也有重要局限。第一个挑战是它们本质上依赖分辨率。若栅格分辨率过粗，狭窄通道或细微的障碍边界可能被漏掉，即使连续空间中存在可行解，规划器也可能找不到。反之，使用极细的栅格会显著增加计算负担，因为栅格单元数随分辨率变细而迅速增长。因此，在分辨率与可处理性之间取得恰当的折中并不简单。

第二个缺点是，基于栅格的规划在机器人复杂度增加时扩展性很差。它对在二维工作空间中运动的简单二维机器人（即位形空间与工作空间重合的情形）有效，但栅格规模会随机器人自由度（DOF）的数量指数级增长。此外，基于栅格的规划需要对自由空间 的精确刻画，而这在高维位形空间中往往难以计算。这些局限促成了基于采样的方法，4.4 节将讨论它们。因此，基于栅格的方法主要用于自由度较少的机器人，或位形空间维数被有意降低的简化规划问题。

总之，基于栅格的规划仍然是一种广泛使用且重要的方法，尤其适用于低维问题。但它对离散化的依赖以及随维数的指数级扩展，限制了它在更复杂机器人系统上的适用性。

组合式运动规划

本节回到运动规划问题的连续表述，讨论组合式方法。其核心思想是构造自由空间 连通性的精确表示，而不借助近似。组合式方法不对空间做任意离散化，而是计算一张路线图（roadmap），用它捕捉 的本质拓扑结构，从而支持在连续空间中的规划。

由于这一性质，组合式运动规划算法被称为精确（exact）的——它们直接在连续位形空间中找路径，不依赖近似。组合式规划器也是完备（complete）的：只要存在路径就保证找到最优路径，否则正确报告失败。这与基于栅格的规划器形成对比——后者只是分辨率完备的，只在所选离散分辨率下存在解时才保证找到。

不过，与基于栅格的方法一样，组合式规划在高维位形空间中会变得计算困难，因为计算 的精确几何、并把它分解为路线图，代价往往高得难以承受。因此，这类方法最适合自由度较少的机器人或低维规划问题。

路线图

路线图是嵌入在位形空间中的图 ，其中每个顶点 对应 中的一个位形，每条边 表示相应位形之间的一条连续、无碰撞路径。令 表示 中顶点所代表的全部位形构成的集合。为使 成为有效的路线图，它必须满足两个关键条件，以保证准确表示 的结构：

  • 1. 可达性（accessibility）： 从任意位形 出发，必须能简单地计算出一条到任意位形 的连续、无碰撞路径。通常取 为离 最近的顶点（假定 是度量空间）。该条件确保自由空间中的每个位形都能在不离开 的前提下连到路线图上。
  • 2. 保持连通性（connectivity-preserving）： 借助可达性条件，必须能把任意两个位形 分别连接到路线图中的某两个 。保持连通性要求：若 中存在从 到 的连续无碰撞路径，则路线图 中 与 之间也必须存在对应路径。换句话说，不会因为路线图未能捕捉自由空间底层的连通性而丢失 中的可行路径。这一性质是组合式规划算法完备性的关键。

一旦满足这些条件，路线图就给出了规划问题的精确表示：顶点对应 中可达区域内的代表位形，边编码它们之间的连通性。运动规划随之归结为图搜索问题：把起始位形与目标位形连到路线图上，在所得的图中搜索路径。

这一结构看起来可能与前面讨论的基于栅格的方法相似，关键区别在于空间的表示方式。路线图是为捕捉 的真实几何与连通性而构造的，而不是把 强行离散到均匀栅格上。换句话说，路线图中的顶点可以对应自由空间内的任意位形，因此可行路径总能被保留在图表示中；而基于栅格的方法可能因为底层离散化过粗而无法表示某些合法路径。这种两步流程——先构造路线图、再做图搜索——为运动规划提供了有力而通用的框架注关于路线图概念的深入讨论，以及完备性与最优性要求的正式定义，请参阅 LaValle (2006)。。

单元分解

如上所述，组合式方法必须构造一个精确编码规划问题的有限数据结构。实现这一点的一种途径是单元分解（cell decomposition）方法：把自由空间 划分为有限个区域（称为单元（cell）），再用这些单元构造路线图。

理解单元分解的一个有用角度，是看使它适合运动规划的三个关键性质：

  • 1. 单元内连通性平凡： 在单元内部从一个位形到另一个位形计算路径必须容易。例如，若每个单元都是凸的，则单元内任意两点都可用一条仍位于 中的直线段相连。
  • 2. 可提取邻接关系： 必须能直接判定哪些单元彼此相邻，从而通过连接相邻单元构造路线图。
  • 3. 查询定位高效： 对给定的起始位形与目标位形 ，应能高效确定它们分别位于哪些单元中。

满足这些条件后，运动规划问题就归结为图搜索问题：顶点对应对每个单元中的代表位形，边连接相邻单元。

其他路线图构建方法

除单元分解之外，人们还发展了其他若干构造路线图的方法，它们往往利用自由空间的几何性质。

LaValle, S. M. Planning Algorithms. Cambridge University Press, 2006.。每种路线图构建方式在计算容易程度、路径质量与鲁棒性之间提供了不同的折中。方法的选择取决于机器人与环境的几何特性，以及当前任务的需求。

基于采样的运动规划

组合法与栅格法的局限——尤其在高维空间中计算复杂度高——推动了基于采样的运动规划（sampling-based motion planning）算法的发展。在高层思路上，这类算法显式回避对 与 的显式表示，转而依靠随机采样来刻画位形空间的结构。具体做法是把 空间中的随机采样与黑箱式的碰撞检测（collision detection）算法结合起来：后者判断某个位形或路径段是否无碰撞（即是否落在 内）。通过逐步连接这些无碰撞样本，基于采样的方法能构建出一张路线图或一棵树结构，在不显式表示自由空间的前提下刻画其可行连通性，实践中带来显著的计算加速。这一范式有几方面优势：

  • 概念简单：算法相对易于理解与实现。
  • 通用性：同一框架适用于不同的机器人与环境。
  • 可扩展性：方法可以超出纯几何情形，处理运动动力学规划、微分约束与不确定性。

与此同时，基于采样的方法也有固有的局限。与精确的组合方法不同，它们对解的存在性或质量给出的保证通常更弱。此外，事先很难知道需要多少样本才能找到解，也很难保证只要存在解规划器就一定能找到。在理论层面，多数方法给出的是概率保证而非确定性保证：它们是概率完备（probabilistically complete）的（即若存在可行路径，则当样本数 趋于无穷时找到它的概率趋于 1）；对某些变体还是渐近最优（asymptotically optimal）的（即若 是 个样本后所找到的最好路径的代价， 是最优代价，则 以概率 1 趋于 ）。这两条性质本质上都是渐近的、概率的：它们不提供有限样本下的保证，只说明失败（或次优）的概率随 增大而消失。这两条性质将在 4.4.3 节进一步讨论。

传统上，基于采样的运动规划算法分为两大流派：概率路线图（probabilistic roadmaps，PRM）与快速探索随机树（rapidly-exploring random trees，RRT）。PRM 是多次查询规划器（multi-query planner），其预计算结构可复用于同一环境中的多个规划问题。相比之下，RRT 是单次查询规划器（single-query planner），针对给定自由位形空间 中特定的起点—目标对 求一个解。尽管有这一区别，两类算法共享两个基本组件。第一个是碰撞检测例程 ，它判断位形 是否落在自由空间 内。第二个是局部规划器 ，它生成一小段路径——通常取位形空间中的直线段，或一段动力学可行的运动——并通过检查碰撞来验证其有效性。

下面概述 PRM 与 RRT，以及它们的理论性质与实践考量。

概率路线图（PRM）

PRM 是运动规划中最具影响力的基于采样的方法之一。在高层上，PRM 是一种多次查询规划器：它在位形空间中随机采样位形并把它们连成图，从而构建一张路线图。PRM 算法包含两个主要阶段：构建阶段（construction phase）与查询阶段（query phase）。构建阶段中，算法用均匀或带偏置的采样策略从 中采样一组位形 ，再用每个采样位形构建一张编码自由空间连通性的路线图。因此，路线图一旦构建完成，就可以通过把起点与目标位形接入路线图并运行一次图搜索，来求解同一环境中的多个规划问题。

设计考量

PRM 的效果取决于若干关键设计决策，它们同时塑造其计算性能与刻画自由空间连通性的能力。首先要考虑的是采样策略。最直接的做法是在位形空间中均匀随机生成位形，只保留落在 中的那些。这种做法覆盖无偏，但在以狭窄通道为主的环境中表现可能很差：这类区域体积小，因而很少被采到。为克服这一局限，人们提出了各种带偏置的采样策略，目标是提高在位形空间困难区域采样的概率。更一般地，启发式偏置策略可以把样本引向对特定规划任务可能更相关的区域，用均匀性换取复杂环境中的有效性。

另一项重要的设计选择是连接采样位形所用的方法。最常用的有两条规则：固定半径规则，即每个顶点尝试与半径 的球内所有样本相连；以及 近邻规则，即每个顶点与最近的 个样本相连。本章余下部分会说明，这两条连接规则都有理论结果支撑，这些结果把 与 的取值同样本数与空间维数联系起来（例如见 Karaman and Frazzoli (2011)注6. Karaman, S., Frazzoli, E. “Sampling-based Algorithms for Optimal Motion Planning.” Int. Journal of Robotics Research 30(7), 846–894, 2011.）。这些结果保证：随着样本数增长，路线图会变得足够连通，能够刻画 的拓扑，而不会引入过多的样本。

PRM 的特性

概率路线图框架特别适合在多次规划查询之间保持静态的环境。由于路线图的构建可能计算代价很高——主要开销在最近邻查询与碰撞检测——只有当预处理的投入能在同一工作空间的大量查询上摊销时，它才最有效。在这些场合，路线图充当可复用的数据结构，紧凑地编码自由空间的连通性，使查询能用标准图搜索算法快速得到答案。

正因如此，PRM 成为那些需要在高维但大体静态的环境中求解大量规划查询的领域的首选方法。它的长处不在于快速给出单个解，而在于构建一个可复用、刻画自由空间拓扑的结构，之后可反复用来高效求解大量查询。

总体而言，PRM 类运动规划算法在实践中被广泛认为能找到「好」路径，即使在高维位形空间中也是如此。但这可能需要大量昂贵的碰撞检测，因而带来可观的计算开销。

Voronoi 偏置

理解 RRT 效率的一个关键洞见，是用 Voronoi 图（Voronoi diagram）的视角来解读它的采样动力学（图 4.13）。树 中的每个顶点都在位形空间中定义一个 Voronoi 胞腔，由所有到该顶点比到其他顶点更近的点组成。由于随机样本均匀分布，扩展某个给定顶点的概率正比于其 Voronoi 胞腔的体积。位于树前沿的顶点往往拥有较大的胞腔，因而更可能被选中扩展。这种Voronoi 偏置（Voronoi bias）隐式地把树向外驱动，快速探索尚未覆盖的区域，而无需任何显式的前沿选择机制。

基于前向传播的算法

把动力学纳入基于采样的规划器，一种实用途径是前向传播（forward propagation）。规划器不直接连接采样得到的状态，而是采样一个控制输入 与一个时长 ，再把系统动力学向前积分，得到新状态。例如，RRT 的运动动力学扩展按如下步骤进行：(i) 采样一个随机状态，并在树中找到它的最近邻 ；(ii) 采样随机控制 与传播时间 ；(iii) 从 出发向前仿真系统，得到新状态。若所得轨迹段无碰撞，就把它加入树，否则丢弃。值得注意的是，在对 的温和正则性假设下，带前向传播的 RRT 变体已被证明是概率完备的。

运动动力学规划因而在单一框架内统一了避障与微分约束，这对机器人学尤为重要：动力学考量会大幅限制可行路径集合，例如在高速地面车辆、空中机器人或具有显著动量的系统中。

概率规划器必须是随机的吗？

一个自然的问题是：基于采样算法的成功，是否从根本上依赖于采样过程的随机性？具体地说，若把 PRM∗ 或 FMT∗ 这类算法去随机化（de-randomized），即在确定性样本上运行，它们的理论保证与实践性能是否仍然成立？

这个问题之所以重要，有几方面原因。确定性采样序列能消除概率不确定性，从而大幅简化安全关键系统中的认证。它们还能让规划器更有效地利用离线计算，并简化最近邻搜索等操作。

近期结果表明答案是肯定的：只要精心选择低散布（low-dispersion）的确定性采样序列，渐近最优性与完备性保证都能保留注26. Janson, L., Schmerling, E., Clark, A., Pavone, M. “Deterministic sampling-based motion planning: Optimality, complexity, and performance.” Int. Journal of Robotics Research 37(1), 46-61, 2018.。因此，随机性对正确性与性能都不是严格必需的。概率采样提供了便利与通用性，而确定性低散布序列能给出同样强的保证，并在可预测性、效率与易于认证方面具有优势。

优缺点

势场法的主要优点是简单且计算高效。这些方法最初是作为移动机器人的在线避障策略提出的注28. Khatib, O. “Real-Time Obstacle Avoidance for Manipulators and Mobile Robots.” The International Journal of Robotics Research 5(1), 90-98, 1986.，适用于障碍物可能事先未知的动态环境。它不需要在图上做复杂搜索，也不需要构建路线图：路径生成只需在机器人当前位形处评估势函数及其梯度。

然而，由于势场规划器本质上是在势函数上做梯度下降，它们容易陷入局部极小。具体来说，规划器可能被困在引力与斥力相互平衡的区域：某个并非目标的位形处合力为零。这一问题常见于含凹形障碍物的环境（例如 U 形陷阱），或狭窄走廊中相对墙壁的斥力抵消了指向目标的引力。因此，标准势场规划器不是完备的，即使存在路径也可能找不到。

为解决局部极小问题，人们提出了多种技术。一种做法是引入随机「抖动」（例如对机器人位形施加小的随机扰动）以逃出局部极小的吸引盆。更有理论依据的方案是构造称为导航函数（navigation function）的特殊势场，可证明除目标外不含局部极小注29. Rimon, E. Exact robot navigation using artificial potential functions. PhD Thesis. Yale University, 1990.。但构造这类函数计算代价高，一般只对简单环境可行。另一种相关方法是波前规划器（wavefront planner）或刷火算法（brushfire algorithm）：它把位形空间离散化（类似栅格法），从目标向外传播一个势波，从而在栅格上生成保证无局部极小的势场。

总之，势场法为局部运动规划与避障提供了快速、反应式的框架。其简单性有吸引力，但由于局部极小问题导致全局规划不可靠，这限制了它作为独立的完备运动规划器的使用。

本章小结

本章把运动规划介绍为把高层任务规范转成可行、无碰撞路径的关键环节。我们把核心问题表述为：寻找一串动作，把机器人从起始位形驱动到目标位形，同时避开障碍物。贯穿全章的一条主线是把运动抽象到机器人的位形空间（ 空间）中，在那里规划归结为在自由空间 中寻找一条连续路径。

我们先讨论了栅格法（grid-based methods），它把位形空间离散化，把问题转化为图上的最短路搜索。由此引入了一族通用的标签修正（label-correcting）算法，包括求最短路的 Dijkstra 算法，以及它的有信息扩展 A∗——后者用启发函数把搜索高效地引向目标。接着转向组合规划（combinatorial planning），这是一种精确方法，通过把连续自由空间分解为简单单元来构造路线图，能保证完备性，但在高维空间中面临计算挑战。随后讨论了基于采样的方法，它们依靠随机采样与碰撞检测来增量式地构建 ，从而避免显式构造自由空间。我们介绍了 PRM 算法——构建自由空间可复用图的多次查询规划器，以及单次查询的 RRT 算法——从起始位形增量式生长一棵树。我们总结了它们的关键理论性质，包括概率完备性与渐近最优性，这些性质催生了 PRM∗、RRT∗ 与 FMT∗ 等更先进的规划器。我们进一步把这些概念扩展到运动动力学规划，它纳入系统动力学；并讨论了确定性低散布采样如何能提供与概率方法相当的理论保证，同时在可预测性与认证方面带来好处。最后介绍了势场法，它通过定义人工势函数把机器人引向目标、推离障碍物来生成路径，能实现快速、反应式的局部规划，代价是可能出现局部极小。

习题 1：A∗ 运动规划

本习题中，你要为若干简单二维环境实现基于栅格的 A∗ 运动规划算法。在文件 ch04/exercises/a_star.ipynb 与 ch04/exercises/a_star.py 中，实现 A∗ 算法的关键部分（见算法 2），在若干随机生成的路径规划问题上运行该算法，然后探索一种平滑所得离散路径的方法——这在实际机器人运动规划任务中很有用。

Data: start node q_S, goal node q_G
Result: shortest path from q_S to q_G (if reachable)

O ← {q_S}                       /* initialize open set */
C ← {}                          /* initialize closed set */
C(q_S) ← 0                      /* initialize cost-to-arrive */
C̃(q_S) ← distance(q_S, q_G)     /* initialize estimated cost */

while O is not empty do
    q ← lowest_est_cost_through(O)
    if q = q_G then
        return reconstruct_path()
    O.remove(q)
    C.add(q)
    for q′ ∈ free_neighbors(q) do
        if q′ ∈ C then
            continue
        if q′ ∉ O then
            O.add(q′)
        else if C(q) + distance(q, q′) > C(q′) then
            continue
        parent(q′) ← q
        C(q′) ← C(q) + distance(q, q′)
        C̃(q′) ← C(q′) + distance(q′, q_G)

return Failure

在本 A∗ 实现中，我们用一张图表示自由空间，通过在确定性栅格上采样状态并做碰撞检测来遍历这张图。这种实现可归类为有信息的确定性采样规划（「有信息」源自 A∗ 的启发函数）。

  • 在 a_star.py 的 Astar 类中实现其余函数。这些函数对应运动规划算法中许多关键的功能模块：
  • is_free：检查某个状态是否无碰撞且有效。
  • distance：计算两点之间的行进距离。
  • get_neighbors：找出给定状态的自由邻居状态。
  • solve：运行 A∗ 运动规划算法。

注意：我们对状态做碰撞检测，但不检测边。这能省下一些计算（碰撞检测往往是运动规划中最昂贵的操作之一）。此外，本例中障碍物与栅格对齐，因此路径仍会保持无碰撞。但在这种特殊情形之外，应加入边碰撞检测和/或膨胀障碍物，以保证避碰。

  • 对真实机器人（它必须跟踪轨迹）而言，在栅格上规划出的路径往往并不理想。本习题中，我们通过对路径节点拟合三次样条来平滑 A∗ 的路径。请在 a_star.ipynb 的 compute_smooth_plan 函数中实现。

注意：确保平滑后的解无碰撞有很多办法（例如对平滑后的路径做碰撞检测，并对平滑参数做二分搜索以找到紧贴障碍物的拟合；或在原规划中膨胀障碍物，为平滑留出额外空间）。这一策略同样可用于几何的基于采样的规划方法。

        parent(q′) ← q
